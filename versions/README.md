# AIRCAT500 Mobile — αρχείο εκδόσεων

Κάθε έκδοση διατηρείται σε δικό της φάκελο, με αμετάβλητο στιγμιότυπο του πηγαίου κώδικα και αναφορά στο αρχικό APK/build. Οι εκδόσεις και οι εφαρμογές δεν αντικαθιστούν η μία την άλλη στο repository.

- [v2.0](v2.0/) — [αρχική λήψη](https://github.com/ApostolosGit/AndroidRadarAnalyzer/releases/tag/v2.0)
- [v2.1](v2.1/) — [αρχική λήψη](https://github.com/ApostolosGit/AndroidRadarAnalyzer/releases/tag/v2.1)
- [v2.2](v2.2/) — [αρχική λήψη](https://github.com/ApostolosGit/AndroidRadarAnalyzer/releases/tag/v2.2)
- [v3.0](v3.0/) — [αρχική λήψη](https://github.com/ApostolosGit/AndroidRadarAnalyzer/actions/runs/45466427812/artifacts/14953903709)
- [v4.0](v4.0/) — [αρχική λήψη](https://github.com/ApostolosGit/AndroidRadarAnalyzer/actions/runs/45473706877/artifacts/14958861500)

Για κάθε νέα έκδοση χρησιμοποιούμε νέο φάκελο versions/vX.Y/ και δεν τροποποιούμε παλαιότερα στιγμιότυπα. Τα source/ είναι πλήρη Git tree snapshots και τα apk/ προορίζονται για τα επαληθευμένα δυαδικά αρχεία. Τα αρχικά releases, tags, branches και ο λειτουργικός κώδικας στο root παραμένουν ως είχαν.
