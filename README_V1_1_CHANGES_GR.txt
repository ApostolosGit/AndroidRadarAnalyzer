AIRCAT500 Mobile v1.1.0 — Android

Ανοιχτό γκρι φόντο RADAR (#EAEDF0). Μαύρο Δ για MSSR, U για combined και ○ για PSR solo.
Εμφανίζονται A:xxxx και C:xxxx / C:---- σε κάθε στόχο, με επιλογές για ταχύτητα, απόσταση, ποιότητα και vectors.
Οι στόχοι παραμένουν ορατοί στο Pause και στο NORTH. Καθαρίζονται μόνον στην εκκίνηση του Play.
Μπάρα χρόνου για μετακίνηση σε οποιοδήποτε σημείο της καταγραφής.
◀◀ για ανάστροφο Replay, ▶▶ για κανονικό, Play/Pause, 1x/2x/4x/8x, βήμα ενός frame.
Φίλτρα: ύψος Mode C σε ft, ταχύτητα σε knots, PSR / MSSR / Combined, alerts, ποιότητα, ακυρώσεις, labels.

Για δοκιμή: ανοίξτε πραγματικό CSV με το πλήκτρο Άνοιγμα. Το Replay ξεκινά αυτόματα.
Στην παύση διατηρείται η εικόνα και στη μπάρα μεταφέρεστε σε άλλο χρόνο.

Η εφαρμογή αυτή είναι έκδοση offline. Δεν προσφέρει ακόμη live ασύρματη λήψη SYNC2USB.
